# שרת הסוכן של דן חריטה

שרת קטן (Node) שרץ ב-Render ומחבר את בועת הצ'אט באתר ל-Claude.

## מה הוא עושה
- **קטלוג אוטומטי:** פעם ביום קורא את `sitemap.xml` של האתר ואת כל דפי המוצרים, ושומר שם, מחיר,
  מחיר לפני מבצע, קטגוריה, תיאור קצר, תמונה והקישור המדויק. מוצר חדש באתר נכנס לסוכן לבד תוך יום.
- **ידע כללי:** מהקובץ `knowledge.md` (משלוחים, איסוף, החזרות, שעות, טיפים לטקסט). עורכים אותו חופשי.
- **קישורים מדויקים:** הסוכן לא כותב כתובות. הוא מסמן מוצר כ-`[[P:מספר]]` והשרת הופך את זה לכרטיס
  עם הקישור מהקטלוג. מספר שלא קיים בקטלוג נזרק, וכל כתובת שהסוכן כתב בעצמו נמחקת.
- **ווטסאפ:** כשהסוכן לא יודע, או בשאלה על הזמנה/הצעת מחיר/אירוע, הוא מוסיף כפתור ווטסאפ
  עם השאלה של הלקוח כבר כתובה בהודעה.
- **הגנה על העלות:** עד 25 הודעות לגולש ב-10 דקות, ועד 1500 הודעות ביום לכל האתר (ניתן לשנות).

## הגדרות (Environment ב-Render)
| משתנה | חובה | מה זה |
|---|---|---|
| `ANTHROPIC_API_KEY` | כן | מפתח ה-API של Claude (console.anthropic.com) |
| `ADMIN_KEY` | מומלץ | סיסמה לדפי הניהול למטה (כל מחרוזת ארוכה) |
| `MODEL` | לא | ברירת מחדל `claude-haiku-4-5-20251001` (מהיר וזול). אפשר `claude-sonnet-5` לתשובות חכמות יותר |
| `DATA_DIR` | לא | תיקייה לשמירת הקטלוג והשיחות. עם דיסק קבוע ב-Render: `/var/data` |
| `DAILY_LIMIT` / `IP_LIMIT` | לא | מגבלות ההודעות |
| `WHATSAPP_NUMBER` | לא | ברירת מחדל 972527772733 |

## דפי ניהול
- `/health` — האם השרת חי, כמה מוצרים בקטלוג ומתי עודכן.
- `/admin/chats?key=ADMIN_KEY` — השיחות האחרונות (מה לקוחות שואלים ומה הסוכן ענה).
- `/admin/catalog?key=ADMIN_KEY` — הקטלוג כפי שהסוכן רואה אותו.
- `/admin/refresh?key=ADMIN_KEY` — לרענן את הקטלוג עכשיו (למשל אחרי הוספת מוצרים).

## הרצה מקומית לבדיקה
```
npm install
cd test && node mocksite.js &        # אתר מדומה
cd .. && SITE_URL=http://localhost:8099 MIN_PRODUCTS=1 MOCK_MODEL=1 \
  ALLOWED_ORIGINS=http://localhost:8099 PORT=3055 node index.js
python3 test/test_widget.py /tmp     # צילומי מסך של הבועה במחשב ובנייד
```
